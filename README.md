# Primavera Sound 2027 · Tier list

Web en català per classificar els artistes del cartell del Primavera Sound 2027.

- Arrossega les targetes o toca-les per triar un nivell.
- Edita els noms dels nivells, desfés canvis i exporta la llista en PNG.
- La classificació es desa localment al navegador de cada persona.
- Targetes compactes amb nom, miniatura i punt de color.

Web estàtica: HTML, CSS i JavaScript, sense instal·lació ni comptes d'usuari.
GitHub Pages publica l'arrel de la branca `main`. El fitxer `.nojekyll` conserva els fitxers sense processament de Jekyll.

Les fonts i els crèdits de les fotos són a `photo-sources.json` i a la fitxa de cada artista. Picture mostra les inicials perquè no s'ha pogut verificar una foto de l'artista.

Projecte no oficial de Primavera Sound.
